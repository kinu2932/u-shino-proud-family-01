A one-line family scene for the [make.fun](https://make.fun) bounty
"Make the AI Judge Feel Proud: A Family Scene".

`main.py` (standard library only) writes the scene to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), gated to
1–280 UTF-8 characters and 1–2 lines.

Run it:

```sh
python3 main.py
```
